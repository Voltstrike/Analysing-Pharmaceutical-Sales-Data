# Analysing Pharmaceutical Sales Data

## Project Overview
This project analyzes pharmaceutical sales data using Python, Pandas, and Matplotlib.

## Dataset
The dataset contains daily sales of drug categories (ATC codes).

## Technologies Used
- Python
- Pandas
- Matplotlib

## Key Analysis
- Total sales by drug category
- Top-performing categories
- Monthly trends
- Seasonal analysis of respiratory drugs (R03)

## How to Run
1. Clone the repository
2. Install dependencies:
   pip install pandas matplotlib
3. Open Jupyter Notebook:
   analysis.ipynb
